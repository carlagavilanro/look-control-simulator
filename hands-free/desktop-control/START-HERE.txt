GETTING STARTED
1. Extract the entire ZIP. Keep the folders next to the executable.
2. Open Hands Free Screen Control.exe on a Windows 10/11 computer.
3. Enter your name. Your saved calibration still works with this update on the same camera and display. Choose a new accuracy check if you want to measure it again.
4. Detailed calibration is the default: 25 screen locations, with two extra visits to the center (27 dots total). Standard uses 13 locations plus two center revisits. Look at the dot until it moves. Blinking is okay.
5. Seven different dots then check accuracy. After a passing check, the controls open automatically. Look near the center of a large tile for TWO SECONDS to select it. Look away after selecting.
6. If the check fails, setup finishes with the measured errors. Adjust alignment collects five new reference points to correct a consistent offset or distortion, followed by seven fresh accuracy checks. You can also test the pointer without sending any clicks, or start a new calibration.

CALIBRATION FEATURES
The app compares combined-eye, separate-eye, and numerical models that learn head-motion correction within each fixed target using whole screen locations left out of training. A more complex map is selected only when it improves those results. Repeated center observations detect drift and are held out together during model comparison.

Calibration waits for settled eye measurements. The camera preview and tracking messages are hidden while collecting a dot so they do not distract from the target. A point that cannot settle pauses with an option to retry that point; the app does not automatically cycle through completed points.

Automatic camera mode requests 1080p and measures tracking speed before calibration. If it is too slow, it requests 720p before collecting points. Actual resolution depends on the camera. Balanced mode requests 720p directly. Camera resolution stays fixed during a calibration.

The result report separates mapping error, sample scatter, head-position rejection, and unavailable eye measurements. Error statistics include finite estimates that fall outside the screen or are rejected for head position; these are not hidden from the results.

The five-point alignment can adjust a saved map after a moderate position change. A larger change requires a new calibration. Alignment points never double as the later accuracy check. The pass criteria have not been relaxed.

SAVING AND PRIVACY
Camera images, raw eye samples, desktop snapshots, and typed text stay in memory on this PC. They are not uploaded to Railway.

Calibration saves numerical model coefficients, camera/display settings, accuracy measurements, and your local profile name. It does not save video, images, or raw eye samples. The fitted map is saved before its separate accuracy check; failing that check does not erase the map.

The companion keeps calibrations.json and a recovery copy in:
%APPDATA%\Hands Free Screen Control\

This is separate from the extracted app folder, so replacing the app does not delete profiles. Browser profiles have separate storage. Existing browser-storage profiles in the companion are imported when used. The companion remembers the last saved name.

Use saved calibration resumes on the same camera and display. Check accuracy again after moving the camera or changing posture. Adjust saved alignment can correct a moderate offset. A changed camera, resolution, display size, or scaling requires calibration for that configuration. Small window-size fluctuations are ignored; substantial changes restart measurements for the new viewport.

LIMITS
This version controls the PRIMARY display. Additional monitors, Android, macOS, drag-and-drop, right/double click, and Windows secure/elevated screens are not implemented.

This is direct horizontal and vertical gaze mapping, not the appliance controller's left/right/center gestures. A normal webcam cannot guarantee individual-pixel gaze accuracy. The zoom controls make small targets easier to select. The dashed pointer outline is based on a previous measured error; it is not a guarantee.

Automated tests use simulated measurements and do not establish accuracy for a real person. The on-device check measures the current person, camera, and position. Pause and check alignment if the pointer drifts.

The executable is an unsigned development build. Follow your school's or organization's software policy if Windows blocks it. Do not disable Windows security protections.

VERSION 0.3.1 REPAIR
New calibrations no longer use head position as a direct predictor of screen location. This avoids learning head/target correlations that can fail after calibration. Correction learned from movement within a fixed target remains available. Detailed calibration visits opposite screen regions instead of sweeping each row in order.

For an existing saved map, first choose Adjust saved alignment (five points). The app compares an offset/scale correction with a new, regularized eye-only map built from those five points. It compares individual-frame errors at an anchor excluded from each fit, so unstable predictions are not hidden by a good median. The new map is used only when that comparison improves sufficiently. Seven fresh accuracy checks measure the repair; none of those checks are used to fit it. Automatic activation requires a passing check. Explicit test mode can be used with unverified accuracy.

The five repair points cover more of the upper and lower screen. You do not need to repeat all 27 calibration observations to try this repair. It is not guaranteed to fix inconsistent eye measurements; the independent check shows whether it worked for the current user and camera.
