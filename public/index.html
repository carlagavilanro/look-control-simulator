independence.

Explore how deliberate selection becomes a device command. This simulation uses the original project’s five-second dwell logic. It never accesses a camera or controls an appliance.

1. Choose a control

Use the arrow keys or the buttons. Selecting a different control clears the countdown.

2. Hold to activate

Hold Space, or press and hold the button below, to simulate a steady center gaze. Release to cancel.

Power selected. Hold for five seconds.

Tracking loss pauses counting. A loss longer than 700 ms resets the hold. Pause, tab switching, and selection changes cancel it. A completed hold sends only once.

What this demonstrates

The real project connects browser eye gestures to a validated Node.js gateway and ESP32 infrared commands. This portfolio edition replaces that transport with an in-memory fan, while reusing the selection state machine. It estimates horizontal eye gestures in the camera prototype, not precise screen gaze.
